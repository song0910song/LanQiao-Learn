# 二分算法

## 1、模板`lower_bound()`函数

```python
def lower_bound(nums, target):
    "在数组nums中找到大于等于target的最小下标"
    left = 0
    right = len(nums) - 1
    
    while left <= right:
        mid = (left + right) // 2 
        # 为防止溢出
        # mid = left + (right - left) // 2
        
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
        
        return left
```

#### 该模板可以解决以下列表中的问题：

|           需求           |              写法               | 如果不存在 |
| :----------------------: | :-----------------------------: | :--------: |
|  >= x的第一个元素的下标  |     $lower\_bound(nums, x)$     |  结果为n   |
|  > x的第一个元素的下标   |    $lower\_bound(nums, x+1)$    |  结果为n   |
| < x的最后一个元素的下标  |   $lower\_bound(nums, x) - 1$   |  结果为-1  |
| <= x的最后一个元素的下标 | $lower\_bound(nums, x + 1) - 1$ |  结果为-1  |
|      < x的元素个数       |     $lower\_bound(nums, x)$     |            |
|      <= x的元素个数      |    $lower\_bound(nums, x+1)$    |            |
|      >= x的元素个数      |   $n - lower\_bound(nums, x)$   |            |
|      > x的元素个数       |  $n - lower\_bound(nums, x+1)$  |            |

## 2. 难题

#### 力扣：3488 距离最小相等元素查询

[]: https://leetcode.cn/problems/closest-equal-element-queries/description/	"3488 距离最小相等元素查询"

```python
class Solution:
    def solveQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        n = len(nums)

        # key: nums的元素；values：nums的元素的下标
        indices = defaultdict(list)
        for i, num in enumerate(nums):
            indices[num].append(i)

        for key, value in indices.items():
            start = value[0]
            end = value[-1]
            indices[key].insert(0, end - n)
            indices[key].append(start + n)
        
        ans = []

        for i in queries:
            if len(indices[nums[i]]) == 3:
                ans.append(-1)
                continue
            j = bisect_left(indices[nums[i]], i)
            distance = min(i - indices[nums[i]][j-1], indices[nums[i]][j+1] - i)
            ans.append(distance)

        return ans
```



 对于**环形**数组，一般用取余，确保数组下标不越界。

 对于这道题，若所要寻找的下标不在`[0, len(n)-1]`范围内，对于左边界，可以用**右边界下标 - 原数组长度**补充左边界；对于右边界，可以用**左边界 + 原数组长度**补充右边界。
